# Project: project-helios (Static Export & GitHub Pages)

## Architecture
- **Frontend**: Next.js 14 (`apps/web`) using App Router.
- **Backend Mocking**: Static JSON API endpoints served from `apps/web/public/api/` (generated by Python script `scripts/export_mock_json.py`).
- **Static Export**: Next.js static HTML export (`output: 'export'`), custom `basePath: '/project-helios'`, and pre-rendered dynamic routes via `generateStaticParams`.
- **CI/CD**: GitHub Actions workflow `.github/workflows/pages.yml` deploying static bundle to GitHub Pages.

## Interface Contracts
### API Endpoints (Static JSON)
- `/api/sites.json` -> list of site objects (including id: `AZ-MESA-001`, `AZ-CHANDLER-001`, and UUIDs)
- `/api/sites/[siteId].json` -> detailed site object for `siteId` (e.g., `AZ-MESA-001.json`)
- `/api/sites/[siteId]/timeline.json` -> timeline data for `siteId`
- `/api/analytics/stages.json` -> stage analytics
- `/api/analytics/provenance.json` -> provenance analytics
- `/api/sources.json` -> sources list
- `/api/map/sites.json`, `/api/map/parcels.json`, `/api/map/infrastructure.json` -> map layers

## Code Layout
- `scripts/export_mock_json.py`: Mock data exporter script
- `apps/web/next.config.mjs`: Next.js configuration (`output: 'export'`, `basePath: '/project-helios'`)
- `apps/web/src/lib/api.ts`: Frontend API client fetching static API JSON files (dual-mode Node/browser)
- `apps/web/src/app/sites/[siteId]/page.tsx`: Dynamic site route pre-rendering logic (`generateStaticParams`)
- `.github/workflows/pages.yml`: GitHub Actions workflow with `actions/configure-pages@v4` and `.nojekyll`
